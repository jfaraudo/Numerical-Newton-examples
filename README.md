# Numerical Integration of the Newton equation of motion
Simple examples in python of different numerical integrators of Newton equations of motion with the typical methods employed in Molecular Dynamics.

We include:

- A pdf file with the theory behind these algorithms.
- A folder with python codes for the integration of the simple harmonic oscillator using different algorithms
- A folder with python implementation of the numerical examples in Chapter 9 of [Feynman Lectures in Physics](https://www.feynmanlectures.caltech.edu/I_09.html)
